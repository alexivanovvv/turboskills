# turboskills

[English](README.md) · **Русский**

Скиллы, которые ускоряют аутентичную работу с ИИ — красиво и по делу.

Коллекция [Agent Skills](https://agentskills.io) для коучей, преподавателей, авторов и всех, кто работает со знаниями. Работают в Claude Code, Codex, Cursor и любом агенте, который понимает формат `SKILL.md`. Большинство скиллов по умолчанию отвечают по-русски.

## Что такое скилл

Скилл - это папка с файлом `SKILL.md` (инструкция для агента) и, по желанию, вспомогательными файлами: справочниками, скриптами, шаблонами. Агент видит короткое описание скилла и подгружает полную инструкцию, только когда запрос под него подходит.

## Скиллы

### texts/ - правка текстов

| Скилл | Что делает |
|-------|-----------|
| [`sokrati`](texts/sokrati/) | Сокращает или причесывает текст, не теряя голос автора: до нужного объема («-30%», «в 2 раза короче») или просто убирает воду, по методу «Пиши, сокращай». Хранит версии v0.1/v0.2… в том же файле со строкой changelog. Личные настройки (файл голоса, типографика, где открыть результат) - в локальном `LOCAL.md`, он не коммитится. |
| [`ochelovech`](texts/ochelovech/) | Очеловечивает русский и английский текст после нейросети точечными правками: убирает канцелярит, штампы ChatGPT, мусор вставки, лишние тире и жирный, остальное оставляет дословно и сверяет, что числа, имена, даты и отрицания на месте. Форк [Vladimir-Human/humanizer-ru](https://github.com/Vladimir-Human/humanizer-ru) (MIT); тесты и стенд сравнения - в замороженном репо [ochelovech](https://github.com/alexivanovvv/ochelovech). |

### slides/ - презентации

| Скилл | Что делает |
|-------|-----------|
| [`slides-generator`](slides/slides-generator/) | Превращает Markdown-файл в однофайловую HTML-презентацию: темный минимал, анимированный SVG-арт на каждом слайде (134 мотива + 25 иконок), 6 тем, режим докладчика, навигация с клавиатуры, заметки, автопоказ, страница настроек. |

### story/ - личные истории

| Скилл | Что делает |
|-------|-----------|
| [`story-heros-journey`](story/story-heros-journey/) | Личная история трансформации по арке Пути героя (6 этапов от обычного мира до возвращения с даром). Для кейсов, лонгридов, глубоких рефлексий. |
| [`story-preodolenie`](story/story-preodolenie/) | История преодоления: 5 гибких элементов (точка А → препятствия → мотивация → ресурсы → точка Б) и 4 схемы композиции. Для блога, портфолио, питча. |
| [`story-authentic-social`](story/story-authentic-social/) | Трушная история для соцсетей и маркетинга по схеме из 6 шагов (хук → зачем → доверие → история → результат → возврат к хуку). Для постов, рилсов, сторис, видео. |

### marketing/ - продажа курсов и услуг

| Скилл | Что делает |
|-------|-----------|
| [`marketing-ladder`](marketing/marketing-ladder/) | Лестница осведомленности Бена Ханта для курса или услуги (ступени 0-5 + после покупки): где сейчас аудитория, аудит текущего маркетинга, сообщения, офферы и CTA по ступеням, тексты, план запуска с датами и метриками переходов. |
| [`marketing-cialdini`](marketing/marketing-cialdini/) | Проверяет, создает или усиливает лендинг, пост, письмо, вебинар или продающую переписку по 7 принципам влияния Роберта Чалдини: профиль 0-3 по каждому принципу, красные флаги фальшивых рычагов, приоритетные правки «было → стало». Только честные рычаги. |

### tools/ - утилиты

| Скилл | Что делает |
|-------|-----------|
| [`disk-space-analyzer`](tools/disk-space-analyzer/) | Находит, что съедает диск, и безопасно чистит: карта диска и графики прямо в терминале, план очистки по уровням риска, результат «было → стало». macOS и Windows. На основе [WhiteMinds/disk-space-analyzer-skill](https://github.com/WhiteMinds/disk-space-analyzer-skill) (MIT). |
| [`usage-insights`](tools/usage-insights/) | Показывает, как вы на самом деле пользуетесь Claude Code: читает локальные логи сессий и собирает HTML-отчет - ритм, типы задач, инструменты, неиспользуемые скиллы, автоматизации, здоровье системы, рекомендации. Данные не покидают компьютер. Только для Claude Code. |

## Установка

**Любой агент** (Claude Code, Codex, Cursor и другие) через [skills CLI](https://github.com/vercel-labs/skills):

```bash
npx skills add alexivanovvv/turboskills -g                 # выбрать скиллы из списка
npx skills add alexivanovvv/turboskills -g --skill sokrati # один скилл
```

**Вручную** - скопируйте папку скилла в папку скиллов вашего агента:

```bash
git clone https://github.com/alexivanovvv/turboskills ~/turboskills

# Claude Code
cp -r ~/turboskills/texts/sokrati ~/.claude/skills/

# Codex
cp -r ~/turboskills/texts/sokrati ~/.agents/skills/
```

Хотите получать обновления через `git pull` - вместо копии сделайте симлинк:

```bash
ln -s ~/turboskills/texts/sokrati ~/.claude/skills/sokrati
```

## Как пользоваться

Просто попросите своими словами - агент сам выберет скилл по описанию. Или вызовите напрямую:

- Claude Code: `/sokrati`, `/slides-generator путь/к/файлу.md`, `/marketing-cialdini audit ./landing/index.html`
- Codex: `$sokrati`, `$slides-generator путь/к/файлу.md`

## Как добавить скилл

PR приветствуются. Каждый скилл:

- одна папка с `SKILL.md` (`name` совпадает с именем папки, `description` до 1024 символов, с фразами-триггерами);
- самодостаточен: скрипты берут пути от папки скилла, ничего не доустанавливают при запуске;
- универсален: работает у любого пользователя, личные настройки - в `LOCAL.md`, который в `.gitignore`;
- по желанию: `README.md` для людей и `agents/openai.yaml` для интерфейса Codex.
