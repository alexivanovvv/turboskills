# AGENTS.md — для агентов, которые правят этот репозиторий

ochelovech (форк Vladimir-Human/humanizer-ru) — навык (Agent Skill), который бережно правит русский и английский ИИ-текст
и сверяет факты. Всё, что получает пользователь, лежит в `skills/ochelovech/`.

## Карта

| Путь | Что это |
|---|---|
| `skills/ochelovech/SKILL.md` | инструкция для агента, главный файл продукта |
| `skills/ochelovech/references/` | примеры «было → стало» и границы признаков; `patterns-en.md` — английские маркеры |
| `skills/ochelovech/scripts/` | `clean_paste.py`, `apply_edits.py`, `edit_budget.py`, `check_facts.py`: только стандартная библиотека Python |
| `eval/` | слепое сравнение с другими навыками на русских ИИ-текстах; `eval/fidelity/` — офлайн-регрессия верности правки |
| `scripts/` | проверка репозитория и сборка архива для Claude.ai |
| `tests/` | тесты скриптов и проверки репозитория |
| `.grace/` | требования, граф модулей и карта проверок (GRACE) |

## Правила

1. Меняешь поведение навыка — прогони сравнение (`eval/README.md`) хотя бы на dev-наборе и
   сравни с прошлым итогом. Правка, которая ухудшает итог, не принимается. Бесплатная проверка
   на лишнее переписывание — `eval/fidelity/README.md`.
2. SKILL.md держи коротким: новое правило заменяет старое, а не добавляется сверху.
   Примеры — в `references/`.
3. Скрипты навыка без внешних зависимостей. Новый случай — тест в `tests/`.
4. Версия меняется одновременно в SKILL.md, `.claude-plugin/*.json`, `.codex-plugin/plugin.json`
   и CHANGELOG; `python scripts/check_repo.py` это проверяет.
5. Переводы строк LF, без невидимых символов в файлах навыка.
6. Не запускать локальные нейросетевые модели (решение владельца).
7. Меняешь поведение скрипта — обнови контракт в коде и `.grace/`.

Перед коммитом:

```sh
python scripts/check_repo.py
python -m unittest discover -s tests
```

Версия 3 (исследования, гейты, пакет PyPI, MCP) — в ветке `legacy-v3`, в main её не возвращать.
