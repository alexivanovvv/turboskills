# Библиотека визуалов

Анимированный геометрический арт для правой половины слайда. Один мотив на слайд, подобранный **по смыслу**. Палитра — **почти-моно: зелёный `#4ade80` (основной) + янтарь `#fbbf24` (акцент, по чуть-чуть)**. Больше цветов не вводить.

## Как устроено

- В `template.html` в `<defs>` лежат **50 готовых мотивов как `<symbol>`** + 5 паттернов (`d_g/d_a` точки, `s_g/s_a` диагональ, `h_g` горизонталь — только зелёный/янтарь).
- Слайд подключает мотив так: `<div class="art"><svg viewBox="0 0 420 560"><use href="#orbital"/></svg></div>`. Класс `mir` → `class="art mir"` даёт зеркальный вариант (больше разнообразия из того же набора).
- Канвас `420×560` (вертикальный — заполняет правую половину). Центр сцены `210,280`.
- Анимация медленная и фоновая: rotate 22–60s, float 5–7s, пульс/ripple 2.4–5s.
- **Зелёный доминирует**, янтарь — 1–2 элемента (ядро, один сектор, галочки). Глубина — через паттерны и opacity, не через новые цвета.

## Правила подбора

- **По смыслу, не по кругу.** Бери мотив из таблицы под тему слайда (чек-лист→`checklist`, рост→`sprout/bars/mountain`, цикл→`cycle/spiral`, история→`storyarc/thread`, выбор→`fork/balance`, одно→много→`prism`…). Разделители — крупные (`rings/interlock/playring/arrow`).
- **Не повторять — ни подряд, ни в пределах сессии.** 50 мотивов + `mir` хватает, чтобы каждый слайд был уникальным. Повтор допустим только если мотивы реально кончились.
- **Между сессиями серии тоже разнообразь.** Делая сессию N — посмотри `href="#..."` в HTML сессий 1..N-1 и выбирай преимущественно другие, чтобы серия не выглядела под копирку.
- **Новый мотив** добавляй как новый `<symbol>` в `<defs>` (тот же стиль, те же 5 паттернов, 2 цвета) и ссылайся `<use href="#новый">`. Не плоди цвета и не усложняй до «грязи».

## Шаблоны для новых мотивов

Сектор-веер вокруг центра (210,280, r=180), угол 60°:
```svg
<path d="M210 280 L390 280 A180 180 0 0 1 300 436 Z" fill="url(#d_g)" opacity=".85"/>
```
Плавающий прямоугольник с паттерном:
```svg
<rect x="90" y="250" width="240" height="66" rx="8" fill="url(#d_g)" opacity=".7">
  <animateTransform attributeName="transform" type="translate" values="0 0;0 -8;0 0" dur="6s" repeatCount="indefinite"/>
</rect>
```
Расходящееся кольцо (пульс):
```svg
<circle cx="210" cy="280" r="30" fill="none" stroke="#4ade80" stroke-width="3" opacity=".6">
  <animate attributeName="r" values="30;180;30" dur="5s" repeatCount="indefinite"/>
  <animate attributeName="opacity" values=".6;0;.6" dur="5s" repeatCount="indefinite"/>
</circle>
```
