# Библиотека визуалов

Анимированный геометрический арт для правой половины слайда. Один мотив на слайд, подобранный **по смыслу**. Палитра арта — **синий `#38bdf8` (основной) + фиолетовый `#c084fc` (акцент, по чуть-чуть)**; UI-акценты зелёный/янтарь в арт не попадают. Больше цветов не вводить.

## Как устроено

- В `template.html` в `<defs>` лежат **104 готовых мотива как `<symbol>`** + 5 паттернов (`d_g/d_a` точки, `s_g/s_a` диагональ, `h_g` горизонталь — только синий/фиолетовый).
- Слайд подключает мотив так: `<div class="art"><svg viewBox="0 0 420 560"><use href="#orbital"/></svg></div>`. Класс `mir` → `class="art mir"` даёт зеркальный вариант (больше разнообразия из того же набора).
- Канвас `420×560` (вертикальный — заполняет правую половину). Центр сцены `210,280`.
- Анимация медленная и фоновая: rotate 22–60s, float 5–7s, пульс/ripple 2.4–5s.
- **Синий доминирует**, фиолетовый — 1–2 элемента (ядро, один сектор, галочки). Глубина — через паттерны и opacity, не через новые цвета.

## Правила подбора

- **По смыслу, не по кругу.** Бери мотив из кластера под тему слайда. Разделители — крупные.
- **Не повторять — ни подряд, ни в пределах сессии.** 104 мотива + `mir` хватает, чтобы каждый слайд был уникальным. Повтор допустим только если мотивы реально кончились.
- **Между сессиями серии тоже разнообразь.** Делая сессию N — посмотри `href="#..."` в HTML сессий 1..N-1 и выбирай преимущественно другие, чтобы серия не выглядела под копирку.
- **Новый мотив** добавляй как новый `<symbol>` в `<defs>` (тот же стиль, те же 5 паттернов, 2 цвета) и ссылайся `<use href="#новый">`. Не плоди цвета и не усложняй до «грязи».
