Бренд / автор

Иллюстрации

Картинки

Как вставлять в слайды готовые изображения — скриншоты, схемы, фото, кадры из старой презентации или из интернета.

Куда класть файл
Внутрь HTML — base64, деск остаётся одним файлом. Рядом — папка img/ возле деска, HTML легче. Ссылкой — URL из интернета как есть.
Формат
WebP q≈88 — в разы легче без видимой потери. Оригинал — как пришло.
Максимальная ширина
Больше — резче на большом экране, но тяжелее файл.

На слайде

Где по умолчанию
Справа — вместо SVG-арта, 50/50 с текстом (.art.pic). Во всю ширину — под заголовком (.wide-pic). Широкие схемы скилл всё равно ставит во всю ширину.
Вписывание
Целиком — ничего не обрезается, подходит для схем и скринов. Заполнить — картинка закрывает всю область с обрезкой краёв, подходит для фото.
Подгонять фон картинки
Чёрный фон скриншота поднимается до фона слайда — не видно прямоугольника.
Автообрезка полей
Срезать пустые поля и обрывки чужого текста по краям, оставить отступ ~3,5%.
