Загрузка…

Основное

Значения по умолчанию для /slides-generator файл.md. Флаги в команде перекрывают их на один запуск. Всё сохраняется сразу в config.json.

Пропорции
Экран для вебинаров или вертикаль для телефона и Telegram.
Тип презентации
Задаёт порядок слайдов. Контент из MD всё равно первичен.

Подписи

Бренд / автор
Внизу слайдов. Пусто — возьмётся из MD-файла.
Тег в углу
Курс и номер сессии, виден на всех слайдах. Пусто — по контексту.

Вид

Главный акцент
Подсветка слов в заголовках, буллеты, первый разделитель.
Второй акцент
Кикеры, предупреждения, второй разделитель.
SVG-арт на слайдах
Анимированная иллюстрация справа. Выключить — только текст во всю ширину.

После сборки

Экспорт
Через export.sh после проверки скриншотами.

Заметки спикера, обновление slides-index.html, проверка скриншотами и открытие результата включены всегда.

Раскладки

Все раскладки, которые знает скилл, с живым превью из template.html. Чаще — брать при любом подходящем контенте, Можно — по ситуации, Выкл — не использовать никогда. Клик по превью — крупно.
