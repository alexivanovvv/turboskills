# Шаблон полного документа

Используй этот шаблон для файла (или для ответа в чат, если файл сохранить нельзя). Разделы, которые не относятся к режиму, убирай целиком, а не оставляй пустыми. Все, чего нет в фактах, – плейсхолдеры в квадратных скобках.

Состав по режимам:

| Раздел | build | audit | audit + build | rung |
|---|---|---|---|---|
| 1. Бриф | да | да | да | коротко |
| 2. Диагноз | да | да | да | коротко |
| 3. Аудит материалов | – | да | да | – |
| 4. Карта лестницы | да | только слабые ступени | да | одна ступень целиком |
| 5. Продуктовая линейка | да | если есть разрывы | да | – |
| 6. Тексты | все ступени | переписанные фрагменты | все ступени | 2-3 черновика + 8-10 хуков |
| 7. План | да | – | да | – |
| 8. Метрики | да | да | да | метрика ступени |
| 9. Вопросы и допущения | да | да | да | да |

---
