# Аудит по 7 принципам

Файл нужен в режимах `audit` и `enhance`. Здесь процедура, шкала, чек-листы по принципам, красные флаги и приоритизация правок.

## 1. Процедура

1. **Прочитай материал целиком** и разбей на блоки: для страницы – секции сверху вниз, для письма – абзацы, для вебинара – этапы, для скрипта – реплики.
2. **Составь банк фактов:** все отзывы, кейсы, цифры, регалии, логотипы, даты, лимиты, бесплатные материалы, упоминания сообщества. Отметь противоречия (разные цифры в разных местах).
3. **Разметь блоки.** Для каждого блока – какие принципы в нем реально работают (не "задуманы", а работают для читателя).
4. **Оцени каждый принцип** по шкале ниже, с учетом места: принцип в неправильной точке получает не больше 1.
5. **Найди красные флаги** – это отдельный список, не часть баллов.
6. **Проверь путь читателя:** первый экран → обещание → доказательства → программа → автор → цена → CTA. На каждом шаге – какой вопрос у читателя и какой принцип на него отвечает.
7. **Составь правки** по приоритету (раздел 5) с переписанными фрагментами.
8. **Составь список "что собрать"** – факты, без которых пустые принципы не закрыть.

## 2. Шкала 0-3

| Балл | Что значит | Пример (социальное доказательство) |
|---|---|---|
| 0 | Принципа нет | Ни одного отзыва |
| 1 | Есть, но общими словами, без деталей или не на месте | "Участники в восторге", три отзыва без имен внизу страницы |
| 2 | Есть, конкретно, с фактами | Отзывы с именами, ролями и результатами, но собраны в одном блоке |
| 3 | Сильно, конкретно и в правильной точке пути | Кейсы с цифрами у цены, отзыв "я не технарь" у FAQ, цифра выпускников в первом экране |

Итог – профиль из 7 баллов. Не складывай их в одну оценку: "14 из 21" ничего не говорит, а "социальное доказательство 1, дефицит 3 с красным флагом" говорит все.

**Нормы по типу материала.** Не каждый материал должен набирать 3 по всем принципам:

| Материал | Должны быть 2-3 | Может быть 0-1 |
|---|---|---|
| Лендинг курса или услуги | Все 7, дефицит – только если он реальный | – |
| Пост на холодную аудиторию | Симпатия, взаимность, единство | Дефицит, обязательство |
| Продающий пост или письмо | Социальное доказательство, авторитет, дефицит, обязательство (маленький шаг) | Взаимность |
| Вебинар или демо | Взаимность, авторитет, социальное доказательство, симпатия, дефицит в конце | – |
| Страница оплаты | Социальное доказательство, дефицит (дата), авторитет (гарантия) | Взаимность, единство |
| Онбординг | Обязательство, единство, взаимность | Дефицит |

## 3. Чек-лист по принципам

### Взаимность
- [ ] Человек получает что-то полезное до первой просьбы (на странице, в эфире, в письме).
- [ ] Бесплатное решает маленькую проблему целиком, а не "затравка".
- [ ] Есть вариант для тех, кто не готов купить: материал, эфир, тест.
- [ ] Бонусы описаны через пользу, а не через стоимость "в рублях".

### Обязательство и последовательность
- [ ] Есть маленький шаг меньше покупки: тест, вопрос, регистрация, лист ожидания.
- [ ] Человек делает что-то сам: отвечает, выбирает, пишет.
- [ ] Есть формулировки, в которых человек узнает свою цель.
- [ ] После покупки есть первое действие в первые 24 часа.

### Социальное доказательство
- [ ] Есть кейсы с цифрами или конкретными результатами.
- [ ] Отзывы с именем, ролью, фото или ссылкой.
- [ ] Авторы отзывов похожи на целевого читателя.
- [ ] Отзывы стоят рядом с сомнениями: у цены, CTA, FAQ, "для кого".
- [ ] Цифры (выпускники, оценка) одинаковые во всех местах.
- [ ] Нет отрицательного социального доказательства ("большинство бросает").

### Авторитет
- [ ] За 5 секунд понятно, почему этому автору можно верить в этой теме.
- [ ] Регалии связаны с продуктом и объяснены, если непонятны.
- [ ] Есть демонстрация: пример, скриншот, разбор, а не только заявления.
- [ ] Есть признание ограничения или блок "кому не подойдет".
- [ ] Биография не стоит перед пользой и не длиннее 5-7 фактов.

### Симпатия
- [ ] Есть живой автор: фото, голос, история.
- [ ] Язык похож на язык аудитории, без канцелярита.
- [ ] Есть хоть одна живая деталь или признанная ошибка.
- [ ] Нет лести и фальшивой дружелюбности.

### Дефицит
- [ ] Ограничение реальное и у него есть причина.
- [ ] Даты не истекли, цены совпадают по всей странице.
- [ ] Дефицит стоит у цены и CTA, а не в первом экране для холодных.
- [ ] Нет обнуляющихся таймеров и вечных "последних мест".
- [ ] Один-два рычага, а не пять на одном экране.

### Единство
- [ ] Читатель может сказать "это про нас".
- [ ] Есть общая идентичность или общее дело, а не только "клиент – продавец".
- [ ] Есть приглашение участвовать: сообщество, совместное создание, выпускники.
- [ ] "Мы" правдивое: автор действительно из этой группы.

## 4. Красные флаги

Каждый флаг – с цитатой, местом и объяснением, почему он вредит. В правках флаги идут первыми.

| Флаг | Почему вредит | Что сделать |
|---|---|---|
| Истекший дедлайн или ранняя цена в прошлом | Читатель решает, что страница заброшена, и не верит остальному | Обновить дату или убрать блок |
| Таймер, который обнуляется | Раскрывается за одну перезагрузку, подрывает все доверие | Убрать или привязать к реальной дате |
| "Осталось N мест" без реального лимита | Ложь, которую видно, если прийти через неделю | Назвать реальный размер группы и причину |
| Отзывы без имен, ролей и деталей | Выглядят придуманными | Собрать отзывы с разрешением, добавить роль и результат |
| Противоречащие цифры | Читатель ловит одну ошибку и перестает верить всем цифрам | Привести к одному проверенному числу |
| Регалии не по теме или без расшифровки | Шум или ощущение пускания пыли в глаза | Оставить 3-5 фактов по делу, расшифровать |
| Давление стыдом и страхом ("все уже впереди, а ты...") | Работает на слабых, отталкивает тех, кто может заплатить | Переформулировать через выгоду и реальную цену бездействия |
| Отрицательное социальное доказательство | Нормализует нежелательное поведение | Переформулировать через тех, кто сделал |
| Галочки по умолчанию, скрытые условия | Подрывают обязательство и доверие | Сделать явным выбором |
| Слишком много способов оплаты или регистрации | Путаница на ступени "готов купить" | Одна главная точка входа |
| Фальшивое "мы" | Раскрывается при первом контакте | Говорить от своего реального опыта |

## 5. Приоритизация правок

Порядок:

1. **Красные флаги** – всегда первыми, даже если правка кажется мелкой.
2. **Нули и единицы в ключевых точках:** первый экран, блок цены, главный CTA, форма оплаты.
3. **Неправильное место:** принцип есть, но стоит не там (отзывы внизу вместо у цены).
4. **Усиления:** конкретика вместо общих слов, варианты формулировок.

Для каждой правки:

```markdown
### [N]. [Что исправить] – [принцип]
Эффект: [высокий / средний / низкий] · Затраты: [низкие / средние / высокие] · Где: [блок]

Что не так: [1-2 предложения]
Было: "[цитата]"
Стало: "[переписанный фрагмент с фактами или плейсхолдерами]"
```

Эффект оценивай по месту и готовности читателя: правка у кнопки оплаты весит больше, чем правка в подвале. Затраты – по тому, есть ли уже факт (переставить отзыв – низкие; собрать 5 новых кейсов – высокие).

## 6. Что собрать

Если принцип нельзя закрыть без новых фактов – не придумывай, а дай задачу:

| Чего не хватает | Как быстро получить |
|---|---|
| Кейсы с цифрами | 3 вопроса выпускникам: что было до, что сделали, что изменилось (с цифрой) + разрешение на имя и фото |
| Отзывы похожих на читателя | Попросить у выпускников нужного сегмента, а не у всех подряд |
| Средняя оценка | Короткая анкета в конце потока, 1 вопрос по шкале 1-5 |
| Регалии по делу | Выписать 5 фактов: годы, число клиентов или выпускников, заметные проекты, сертификации, выступления |
| Реальный лимит | Решить, сколько человек формат выдерживает, и объяснить почему |
| Бесплатная польза | Выбрать один самый частый вопрос аудитории и сделать на него ответ-инструмент |
| Идентичность сообщества | Спросить выпускников, как они называют себя и что их объединяет |

## 7. Путь читателя по странице

Проверь, есть ли ответ на вопрос читателя на каждом шаге:

| Шаг | Вопрос читателя | Какие принципы отвечают |
|---|---|---|
| Первый экран | "Это для меня? Почему стоит читать дальше?" | Единство, авторитет (одна строка), социальное доказательство (одна цифра) |
| Проблема | "Меня поняли?" | Симпатия, единство |
| Решение и результат | "Что конкретно я получу?" | Авторитет (демонстрация), социальное доказательство (кейс) |
| Программа | "Как это устроено, справлюсь ли?" | Обязательство (маленькие шаги внутри), социальное доказательство |
| Автор | "Кто это и почему ему верить?" | Авторитет, симпатия |
| Отзывы | "У таких, как я, получилось?" | Социальное доказательство, единство |
| Цена | "Стоит ли это денег?" | Контраст, социальное доказательство, дефицит (дата) |
| FAQ и "кому не подойдет" | "А если...?" | Авторитет (надежность), социальное доказательство |
| CTA | "Что сделать сейчас?" | Дефицит (реальный), обязательство (маленький шаг для неготовых) |
| После формы или оплаты | "Правильно ли я сделал?" | Обязательство, единство, взаимность |
