# Шаблон полного документа

Используй этот шаблон для файла (или для ответа в чат, если файл сохранить нельзя). Разделы, которые не относятся к режиму, убирай целиком, а не оставляй пустыми. Все, чего нет в фактах, – плейсхолдеры в квадратных скобках.

Состав по режимам:

| Раздел | audit | create | enhance | audit + create |
|---|---|---|---|---|
| 1. Контекст | да | да | да | да |
| 2. Банк фактов | да | да | да | да |
| 3. Профиль по 7 принципам | да | – | до и после | да |
| 4. Красные флаги | да | – | да | да |
| 5. Разбор по блокам | да | – | коротко | да |
| 6. Правки по приоритету | да | – | – | да |
| 7. Текст | – | целиком | обновленный текст целиком | целиком |
| 8. Карта "блок → принцип" | – | да | список изменений | да |
| 9. Что собрать | да | да | да | да |
| 10. Вопросы и допущения | да | да | да | да |
